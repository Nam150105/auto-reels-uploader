1 Nhấn nút "Mở Graph API Explorer" ở trên (sẽ mở tab mới).
2 Tại mục Meta App, chọn ứng dụng: Quản lý page (App ID: 1469615908436980).
3
Tại mục User or Page, chọn Get User Access Token và thêm các quyền sau:
pages_show_list business_management pages_read_engagement pages_manage_metadata pages_read_user_content pages_manage_posts pages_manage_engagement
4 Nhấn Generate Access Token và chấp thuận các quyền trên cửa sổ Facebook hiện ra.
5 Sao chép toàn bộ mã trong ô Access Token, quay lại đây và dán vào ô bên dưới.
6 Nhấn nút "Liên kết Facebook" để hệ thống tự động đồng bộ tất cả Fanpage.
